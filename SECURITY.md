# Security and vehicle safety

This experimental project is not affiliated with Leapmotor and must not be
regarded as a production-ready vehicle control system.

Never include credentials, private keys, PKCS12 bundles, account tokens, VINs,
precise coordinates, database backups or raw diagnostic exports in issues/PRs.
Application credential provisioning is not supplied by this repository.
The code license does not grant rights to third-party credentials or APKs.

Only operate a vehicle you are authorized to control. Cloud acceptance is not
physical confirmation. Never retry an ambiguous command automatically. An old
parked telemetry frame does not prove the vehicle remains parked. Complete
physical testing before relying on any command in an unattended installation.

Please use GitHub private vulnerability reporting when enabled for this
repository. Otherwise contact the maintainer privately before disclosing a
security-sensitive reproduction. Do not attach secrets to a public issue.
